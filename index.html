Developer Journal

  1. Starting Project CS

    July 21, 2026

    I created Project CS as my first major development project and began using it to document my journey toward becoming a full-stack developer and technical founder.

  2. Learning Semantic HTML

    July 23, 2026

    I learned how semantic HTML elements give a webpage meaningful structure. I used sections, navigation, articles, lists, headings, and accessible labels to build the first version of the Project CS homepage.

  3. Learning HTML Forms

    July 23, 2026

    I learned how to create HTML forms using inputs, labels, buttons, and other form elements. I also learned why labels and organized form structure are important for accessibility.

  4. Building Layouts with Grid and Flexbox

    July 26, 2026

    I learned how CSS Grid and Flexbox solve different layout problems. I used grid for major page and card layouts, while using Flexbox for navigation, badges, buttons, and smaller component arrangements.

  5. Making the Website Responsive

    July 27, 2026

    I adapted Project CS for desktop, tablet, and mobile screens using media queries. I learned how layouts can change from multiple columns to a single column when screen space becomes limited.

  6. Creating the Project CS Theme

    July 28, 2026

    I designed the first complete visual theme for Project CS using CSS variables, reusable colors, borders, buttons, panels, and status styles.

  7. Creating Reusable Components

    July 28, 2026

    I created reusable designs for world cards, project cards, technology, status badges, progress displays, achievement cards, and roadmap nodes.

  8. Building the Journey Dashboard

    July 28, 2026

    I created a dashboard that displays my current programming world, active project, current focus, completed achievements, and overall progress.

  9. Designing the Visual Learning Roadmap

    July 29, 2026

    I designed a game-inspired learning roadmap that shows completed, current, and locked milestones. I used CSS Grid to position the nodes and SVG paths to connect them.

  10. Creating a Responsive SVG Roadmap

    July 30, 2026

    I built separate SVG routes for desktop and mobile layouts. This taught me how SVG coordinates, paths, viewbox dimensions, and Bézier curves control visual shapes.

  11. Building a Multi-Page Website

    July 30, 2026

    I expanded Project CS from one webpage into a multi-page website with Home, Projects, and About pages. I learned how relative paths connect pages, stylesheets, and images across folders.

  12. Creating the Projects Archive

    July 30, 2026

    I built a dedicated Projects page with a project index sidebar and reusable project cards. The page is designed to grow as I complete more projects.

  13. Building the About Page

    July 30, 2026

    I created an About page explaining who I am, why Project CS exists, how the journey system works, and what I want to achieve in the future.

  14. Designing the Developer Journal

    July 30, 2026

    I transformed the Developer Journal into a chronological timeline so Project CS can record how my knowledge, projects, and development process evolve over time.

  15. Starting JavaScript in Project CS

    July 31, 2026

    I began adding JavaScript to Project CS and learned how the DOM lets JavaScript select and update elements on the page. I also started moving homepage information away from being completely hard-coded.

  16. Moving Toward a Data-Driven Homepage

    August 2, 2026

    I started organizing changing website information in JavaScript and using functions to update the homepage. This introduced the idea of keeping data separate from the HTML that displays it.

  17. Making the Developer Journal Interactive

    August 12, 2026

    I used JavaScript state, events, NodeLists, indexes, and the hidden property to make the Developer Journal display only the latest three entries by default while allowing the rest to expand and collapse.

  18. Making the Roadmap State-Driven

    August 13, 2026

    I rebuilt the learning roadmap so JavaScript determines which steps are complete, current, or locked from one current-step value. I learned about data attributes, dataset, classList, and deriving UI from state.

  19. Connecting Journey State to Interaction

    August 14, 2026

    I connected the roadmap state to more of Project CS. Progress and Current Focus now derive from the current step, while Continue Journey scrolls to that step and briefly highlights it with a pulse animation.
